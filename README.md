# 🤖 AI-SDLC-April-2025-Homework

## 📌 Overview

Welcome to the **AI-SDLC-April-2025-Homework** repo! This project showcases how Artificial Intelligence (AI) can be woven into the traditional Software Development Life Cycle (SDLC) to improve efficiency, creativity, and automation across every phase of development.

Whether you're just starting to explore GenAI for engineering workflows or you're deep into building intelligent assistants, this repo offers hands-on examples and structured patterns for modern development.

## 🚀 Features

- 🧠 **Requirements Analysis**  
  Extract and structure software requirements using Natural Language Processing (NLP).

- 🏗️ **Design Suggestions**  
  Use historical data and LLMs to guide architectural choices and system designs.

- 🧪 **AI-Driven Testing**  
  Automatically generate test cases from feature descriptions and past bugs.

- 📈 **Predictive Maintenance**  
  Forecast potential issues using AI models before they impact production.

- 📝 **LLM Prompting Examples**  
  Demonstrates prompt engineering for structured generation tasks like email writing, JSON outputs, and feedback summaries.

## ⚙️ Installation (Using VSCode not GitHub Workspace)

Clone the repo and install dependencies to get started:

```bash
git clone https://github.com/Lwhieldon/AI-SDLC-April-2025-Homework.git
cd AI-SDLC-April-2025-Homework

# (Optional) Create a virtual environment
python -m venv venv
source venv/bin/activate  # Windows: venv\Scripts\activate

# Install Python dependencies
pip install -r requirements.txt
```

## 🧪 Usage

Each subfolder under `workshops/` represents a hands-on AI task mapped to an SDLC phase. These include:

- 🗂️ Prompt engineering walkthroughs
- 📬 Email & JSON structured output generation
- 📄 PDF QA with conversational UI
- 📊 Logging and visualization using `datasette`

> Run any app or notebook using your favorite IDE or Jupyter environment.
